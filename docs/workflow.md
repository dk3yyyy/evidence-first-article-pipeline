# Evidence-first workflow

## 1. Define

Lock the intended publication, audience, reader outcome, thesis, scope, freshness requirement and disclosure constraints. If a consequential choice is unknown, record it instead of silently guessing.

## 2. Research

Prefer primary sources. Open every material source and record title, author or publisher, canonical URL, date, access level, relevance and limitations. Search snippets are discovery aids only.

## 3. Interrogate

Seek counter-evidence. Separate fact, interpretation, estimate, prediction and opinion. Preserve sample limits, jurisdiction, version and uncertainty. Remove or qualify claims that cannot be verified.

## 4. Build the claim ledger

Assign a stable claim ID to each material statement. Map it to inspected source IDs and state its allowed scope. The ledger is the evidence authority for drafting and later audits.

## 5. Outline and plan visuals

Build an argument, not a catalogue of facts. Every section should change the reader's understanding. Plan visual questions, data provenance, placement, captions, alt text and exports before drafting.

## 6. Draft

Draft from the brief, ledger, sources and outline. The writing role may improve explanation and structure but may not create facts.

## 7. Fingerprint, edit and reconcile

Fingerprint the evidence-sensitive surfaces before a dedicated editorial pass. Compare the candidate with the locked master. A deterministic pass is necessary but not sufficient; remap changed claims to the ledger.

## 8. Validate

Check links, visual exports, mobile readability, captions, alt text, metadata, platform formatting and the final publication-status marker. Package only the last validated write.

## 9. Approve and publish

Draft approval is not publication approval. Show the exact destination, account, title, assets and delivery settings. Publish only after explicit authorization, then verify the clean public URL independently.
